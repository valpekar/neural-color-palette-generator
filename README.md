# Text-to-Palette Generator using Google Gemini

Generate beautiful color palettes from text prompts using Google Gemini AI.

## Features
- Enter a theme or description (e.g., "autumn forest", "melancholy neon")
- Get a palette of 5–7 colors generated by Google Gemini
- See your palette as color swatches with hex codes
- Export palettes as SCSS variables
- Web interface (Flask backend + HTML/CSS/JS frontend)

## Setup

### 1. Clone the repository
```sh
git clone https://github.com/valpekar/neural-color-palette-generator.git
cd neural-color-palette-generator
```

### 2. Install dependencies
```sh
pip install -r requirements.txt
```

### 3. Configure your Google Gemini API key
Edit `config.py` and set your API key:
```python
API_KEY = "your-google-api-key"
GEMINI_MODEL = "models/gemini-1.5-flash"  # or another supported model
PALETTE_SIZE = 6
```
Or, create a `.env` file:
```
GOOGLE_API_KEY=your-google-api-key
```

### 4. Run the backend
#### For local development (default: http://127.0.0.1:5000):
```sh
HOST=127.0.0.1 python app.py
```
#### For cloud/Render.com (default: http://0.0.0.0:$PORT):
```sh
python app.py
```
- The app will use the `HOST` environment variable if set, otherwise defaults to `0.0.0.0` (cloud) or you can set it to `127.0.0.1` for local-only.
- The app will use the `PORT` environment variable if set (as on Render), otherwise defaults to 5000.

### 5. Open the web interface
Go to [http://localhost:5000/static/index.html](http://localhost:5000/static/index.html) in your browser (replace port if needed).

## Usage
1. Enter a prompt describing your desired palette (e.g., "retro synthwave").
2. Click "Generate Palette".
3. View the generated color swatches and hex codes.
4. (Optional) Use the exported `palette.scss` file in your project.

```
app.py                   # Flask backend

```
